1. IP Finder (PC 프로그램)

PC에서 실행하는 탐색 도구입니다. 저장소 python/SnmpFinder.py 를 실행하거나, 빌드된 실행 파일로 구동합니다. 동일 LAN에서 UDP 브로드캐스트(포트 1234)로 모듈을 찾고 네트워크·TRAP·웹 설정을 반영할 수 있습니다.
구역설명
네트워크 정보IP, 게이트웨이, 서브넷, MAC, VERSION 확인·편집(VERSION은 읽기 위주).
TRAP · 웹 서비스TRAP/WEB 사용 여부, TRAP IP(최대 5곳), 하단 트랩 테스트·설정 적용·검색.
발견된 장비브로드캐스트 응답으로 찾은 목록. 행을 선택하면 상단 필드에 값이 채워집니다.
  • 검색: 디스커버리 메시지를 브로드캐스트하여 모듈을 찾습니다.
  • 설정 적용: 입력한 네트워크 및 TRAP/웹 옵션을 모듈에 전달합니다(MAC 등 대상 지정).
  • 트랩 테스트: TRAP 통신 확인용 테스트를 보냅니다.

2. 웹 화면 (모듈 내장 페이지)

브라우저로 접속합니다. 로그아웃은 우측 상단 Logout.

login.html — 로그인

사용자 ID·비밀번호 입력 후 로그인하면 세션이 활성화되고 상태 화면으로 이동합니다.

basicInfo.html — BMS·축전지·운전·이벤트·제어

왼쪽 메뉴로 전환합니다: BMS 데이터, 축전지 상태, BMS 운전상태, 이벤트로그(주소 해시 #eventlog), BMS 제어(#control).

index.html — 네트워크 구성

IP·MAC·서브넷·게이트웨이, SNMP Access Control(Access IP·Community·권한), TRAP 목적지, WEB 활성 등을 설정합니다.

snmpTest.html — SNMP TEST

OID 입력 후 GET 요청. 하단 참고 표의 행을 클릭하면 OID가 입력됩니다. 아이에프텍 Rectifier 전체 표는 이 페이지에만 완전히 수록되어 있습니다.

help.html

본 문서(사용 설명서)입니다.

fileUpload.html — 웹 자산 업로드

HTML·CSS·JS 등 SPIFFS 업로드용(여러 파일). 장비 펌에서 제공하는 업로드 API에 맞춰 동작합니다.

serverIndex.html 펌웨어(.bin) 업데이트

.bin 바이너리 전용 업로드 안내 페이지입니다. 일반 웹 파일은 fileUpload.html 계열 경로를 사용합니다.
